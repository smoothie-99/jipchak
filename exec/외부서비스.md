### 1-2. RunPod (유료 GPU 클라우드)

| 항목 | 값 |
|------|-----|
| 서비스 URL | https://www.runpod.io/ |
| 용도 | AI 모델 추론 전용 GPU pod (PyTorch + ultralytics YOLO + GR-ConvNet) |
| GPU | RTX 4000 Ada (또는 동등) |
| Base image | `runpod/pytorch:2.4.1-py3.10-cuda12.1.1-devel-ubuntu22.04` |
| 외부 노출 URL | `https://<pod-id>-8000.proxy.runpod.net` (RunPod 자동 발급, Cloudflare 프록시) |
| 가입 방법 | RunPod 회원가입 → 결제 수단 등록 → 크레딧 충전 |
| 비용 | 시간당 약 $0.3 ~ $0.7 (GPU 모델에 따라) |
| 필요 정보 | 계정 이메일, API key (선택 — pod 자동화 시), 결제 카드 |

**활용 내용**:
- FastAPI + uvicorn 으로 WebSocket 서버 운영 (`/ws/camera`, `/ws/stream`)
- YOLOv8-seg + GR-ConvNet 실시간 추론 (0.5초 주기)
- Spring Boot 로 영상/게임 로그 POST 호출
- 외부 접속 URL 은 pod 재시작 시 변경될 수 있음 → `infra/.env` 의 `VITE_WS_STREAM_PATH` 갱신 필요

**관리 콘솔**: https://www.runpod.io/console/pods

---

### 1-3. Cloudflare (RunPod 자동 적용)

| 항목 | 값 |
|------|-----|
| 용도 | RunPod proxy URL 앞단의 자동 CDN/TLS |
| 가입 방법 | 별도 가입 불필요 — RunPod 가 자동으로 `*.proxy.runpod.net` 도메인 제공 |

### 4-1. Let's Encrypt (무료 TLS 인증서)

| 항목 | 값 |
|------|-----|
| 서비스 URL | https://letsencrypt.org/ |
| 용도 | k14d108.p.ssafy.io 의 HTTPS 인증서 발급 |
| 가입 | 불필요 (certbot CLI 만으로 발급 가능) |
| 비용 | 무료 |
| 유효 기간 | 90일 (자동 갱신 필요) |

**활용 내용**:
- EC2 에서 `certbot certonly --standalone` 으로 발급
- 발급 위치: `/etc/letsencrypt/live/k14d108.p.ssafy.io/`
- Nginx 컨테이너에 `/etc/letsencrypt:/etc/letsencrypt:ro` 로 마운트
- 갱신: `sudo certbot renew && docker compose restart nginx`

## 6. 사용하지 않은 외부 서비스

> 일반적인 SSAFY 프로젝트에서 자주 쓰이지만 본 프로젝트에서는 **사용하지 않음**.

| 항목 | 사유 |
|------|------|
| 소셜 로그인 (Google / Kakao / Naver OAuth) | 키오스크 기반 익명 사용. 로그인 없이 QR 영상 다운로드만 제공 |
| 카카오 알림톡 / SMS | 영상 전달은 QR 코드 + 모바일 다이렉트 다운로드로 처리 |
| AWS S3 / 외부 객체 스토리지 | EC2 로컬 디스크에 영상 저장 후 Spring Boot 가 `/videos/` 엔드포인트로 서빙 |
| Firebase / FCM | 푸시 알림 사용 안 함 |
| Photon Cloud / 실시간 통신 SaaS | 자체 WebSocket + RelayHub 로 fan-out 처리 |
| Mixpanel / Google Analytics | 사용량 통계는 어드민 대시보드(Recharts)로 자체 구현 |
| Sentry / Datadog | 로그는 컨테이너 stdout + nohup tee 로만 수집 |
| OpenAI API / 외부 LLM | AI 모델은 자체 호스팅 (RunPod) |
| Stripe / 결제 | 결제 기능 없음 |
